## 📁 Estructura del Repositorio de Entrega

El proyecto sigue rigurosamente el esquema requerido para la entrega oficial:

```text
know-your-target/
├── README.md           # Identificación, objetivo elegido y enlaces
├── alcance.md          # Programa, reglas, restricciones y alcance oficial
├── scope.txt           # Formato de objetivos en texto plano para el agente
├── cuaderno.md         # Registro cronológico del proceso manual paso a paso
├── mapa.md             # Informe y mapa final de la superficie de ataque
├── comparativa.md      # Análisis comparativo: trabajo manual vs agente autónomo
├── img/                # Evidencias gráficas (capturas de pantalla)
└── agente/             # Segunda parte: ejecución y herramientas del agente
    ├── src/            # Código y scripts de herramientas añadidas
    ├── pruebas.md      # Comprobaciones sobre scope.txt
    ├── instrucciones.md# Prompt ajustado del agente
    ├── traza.jsonl     # Ejecución y traza completa
    └── informe.md      # Informe generado automáticamente por el agente
```
